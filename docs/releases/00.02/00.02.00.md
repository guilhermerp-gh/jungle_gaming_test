# Release Notes - Versão 0.2.0

**Data de Lançamento:** 17 de outubro de 2026

## 📝 Resumo Executivo

A versão 0.2.0 introduz a camada de persistência financeira em banco de dados relacional com garantias rígidas de integridade. A partir desta versão, todas as operações de carteira contam com bloqueio seguro contra saldo negativo, histórico de extrato contábil imutável (à prova de adulterações ou exclusões acidentais) e mecanismo anti-duplicação que impede que apostas ou estornos sejam cobrados mais de uma vez, mesmo em situações de requisições simultâneas.

---

## 🆕 Recursos Adicionados

- **Persistência Relacional de Carteiras e Apostas:** Mapeamento completo e armazenamento durável das carteiras de jogadores e transações financeiras.
- **Livro-Razão Imutável (Audit Ledger):** Registro contábil append-only com validação matemática estrita de saldo inicial, movimentação e saldo final em cada entrada.
- **Mecanismo Anti-Duplicação de Reversões:** Proteção nativa no banco para garantir que apostas sejam revertidas (estorno ou cancelamento) no máximo uma única vez.
- **Fila Transacional de Eventos (Transactional Outbox):** Armazenamento de eventos no mesmo ciclo atômico da transação financeira para envio assíncrono garantido.
- **Runner Nativo de Migrações:** Scripts dedicados em Bun para aplicação (`migration:up`) e reversão (`migration:down`) de esquemas de banco de dados.
- **Workflow e Pipeline Automatizado de Testes:** Comando unificado `bun run test:pipeline` e comando interativo `/run-tests` que executam checagens fail-fast completas.

## 🔧 Modificações

- Aprimoramento da entidade contábil do ledger com getters de conveniência para consulta de metadados das transações.
- Atualização da documentação do projeto com guia detalhado de acesso ao banco via clientes visuais e execução de testes de integração.
- Bump da versão do projeto para `0.2.0` no `package.json`.

## 🐛 Correções

- Correção no acoplamento de execução do CLI do MikroORM, substituindo o executável baseado em Node.js incompatível por um script nativo com runtime Bun.

## 🏗️ Alterações Estruturais

- Implementação da camada de portas de aplicação (`src/application/ports/`): `WalletRepository`, `WagerTransactionRepository`, `LedgerRepository`, `InboxRepository`, `OutboxRepository` e `UnitOfWork`.
- Implementação dos repositórios e Unit of Work transacional com isolamento via `AsyncLocalStorage`.
- Modelagem de schemas desacoplados via `EntitySchema` e mapeadores bidirecionais (`rehydrate`).
- Criação da migração inicial com triggers de auditoria em PL/pgSQL e índices parciais de chave única.
